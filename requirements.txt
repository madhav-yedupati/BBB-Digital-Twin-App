# NOTE on scikit-learn / xgboost versions:
# The Tier 1/2/3, ABC (rf/xgb), and calibration models are loaded from
# pickled objects in models/. Pickled sklearn/xgboost models are only
# guaranteed to unpickle cleanly with a version that's compatible with
# whatever version they were trained/pickled with -- if you hit an
# unpickling error or a silent accuracy drop after deploying, check the
# scikit-learn/xgboost version used locally when the .pkl files were
# created (pip show scikit-learn / pip show xgboost) and pin these two
# lines to match exactly before troubleshooting anything else.
#
# PINNED (not >=) as of Sept 2026: local training environment uses
# scikit-learn 1.6.1 and xgboost 3.2.0 exactly. Deploying with >= let
# Streamlit Cloud install scikit-learn 1.9.1, which cannot unpickle
# these models -- sklearn restructured its internal _loss module between
# 1.6.x and 1.9.x, causing "ModuleNotFoundError: No module named '_loss'"
# specifically on GradientBoostingRegressor. Do not loosen these two
# pins without re-pickling the models against the newer version first.
#
# scikit-learn is also used at runtime (not just for the pickled models)
# for the optional Gaussian Process surrogate fit in the "My Chip" tab
# once a user has 6+ calibration compounds -- the app degrades gracefully
# to a linear fit if scikit-learn is somehow unavailable, but since it's
# already required for the pickled models above, it will always be
# present in this deployment.
